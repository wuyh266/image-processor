## 2. 全链路与模块关系

```text
启动：配置 → 专属目录锁 → MySQL/数据库锁 → 迁移 → 恢复 → worker → HTTP
同步：入口名额 → 上传名额 → 限读/预检 → 规格检查 → 同键共享
      → Redis → MySQL 结果索引 → 必要时等待计算/解码/缩放/编码
      → 发布文件 → 保存索引 → 写缓存 → 流式返回
异步：上传/全部规格检查 → 发布源文件 → 事务保存 job/items → 202
      → worker 原子领取/token → 同一个结果 Resolver → 条件写回终态
查询：按 job 汇总 items；成功项读取持久化结果并下载
退出：取消服务 context → 等 HTTP/worker/共享工作 → 释放锁与连接
```

容量默认值是教学参考起点：HTTP 16、上传 4、计算 2/等待 8、worker 2、活跃任务规格 128。源图 2000 万像素、目标 800 万像素、单文件 10 MiB、请求体 11 MiB、编码结果 16 MiB。它们共同降低失控风险，但不能简单相加得出严格的进程内存上限。

## 3. 实现前的理论核验结论

| 要核验的说法 | 与完整实现一致的表述 | 在哪里验证/仍需什么证据 |
|---|---|---|
| 文件小就安全 | 压缩字节、源像素、目标像素、输出字节各自约束 | S01/S02 成功和边界测试已运行 |
| 一个 sem 保护全部内存 | 上传、整个请求、等待和共享计算有各自容量与生命周期 | S03 名额测试已运行；整服务负载待测 |
| context 到期计算立即停止 | 等待可取消，CPU 函数在阶段边界观察 | S04/C02 独立测试；容器退出待测 |
| 单个请求取消可取消共享任务 | 各 caller 独立等待，共享工作属于服务 | C02 取消与共享退出测试已运行 |
| Commit 报错等于未提交 | 可能回复丢失，需要新连接确认；无法确认时保留职责/文件 | A01/A02/A03 代码已核验；断网故障注入待做 |
| 数据库命名锁足以支持任意恢复 | 连接断开会丢锁，还需专属目录互斥与旧实例退出前提 | A03 目录锁已测；SQL/容器恢复待测 |
| worker 状态写失败记日志即可 | 必须继续完成当前写回，否则 processing 会遗留 | A02 worker 保留职责；真实 DB 故障待做 |
| 原子 Rename 等于文件和 SQL 原子事务 | 同目录发布减少半文件暴露，跨资源仍需查证与补偿 | A03 文件测试已测；断电保证不在支持范围 |
| Redis 过期会删图片 | TTL 仅清索引，文件由终止任务保留策略维护 | C01/A03 实现；真实维护待测 |
| Redis 清空等于全新计算 | MySQL 仍可能命中已有结果，查看实际计算增量 | C01/P01；真实实验待做 |
| 小池一定提升整个服务 QPS | 暂存保留容量更清楚，收益要同条件测量 | P01 微基准已运行；业务压测待做 |
| 测试包 PASS 等于依赖验收 | 独立测试与缺依赖 SKIP 分别记录 | 本文第 6 节与集成测试入口 |

### 异步提交、查询、下载

PowerShell 5.1 的原生命令参数传递可能改变 JSON 双引号，因此将 specs 写入文件并用 curl 的字段文件语法传递。

```powershell
$utf8 = New-Object System.Text.UTF8Encoding($false)
$specsFile = Join-Path (Get-Location) '.runtime-data/specs.json'
[System.IO.File]::WriteAllText($specsFile, '[{"width":320,"format":"png"},{"width":160,"format":"jpeg"}]', $utf8)
$accepted = curl.exe -f http://127.0.0.1:18080/jobs -F "file=@.runtime-data/samples/sample-000.png;type=image/png" -F "specs=<$specsFile" | ConvertFrom-Json
$jobId = $accepted.job_id
$job = Invoke-RestMethod "http://127.0.0.1:18080/jobs/$jobId"
$job | ConvertTo-Json -Depth 8
```

稍后重复查询，直到所有规格终止。下载只对 `succeeded` 的规格开放：

```powershell
$job = Invoke-RestMethod "http://127.0.0.1:18080/jobs/$jobId"
foreach ($item in $job.items) {
    if ($item.state -eq 'succeeded') {
        curl.exe -f "http://127.0.0.1:18080$($item.download_url)" -o ".runtime-data/$($item.id).$($item.format)"
    }
}
```

全部 pending 时总状态 pending；任一规格仍处理或部分终止时为 processing；全部终止且任一失败时总状态 failed。成功规格仍可下载，必须查看 items 判断部分成功。

验证同一实例恢复时，始终使用相同数据库和相同数据根目录；容器图片卷与本机 `.runtime-data` 不同，不应在同一数据库上切换不同文件根目录。HTTP、worker 和共享计算都受服务生命周期约束，退出时总等待预算默认 10 秒。

### 故障与恢复验收

先记录一次成功任务 ID、输出规格、结果可解码性及 `/stats`。依次进行以下独立实验，保存日志和实际结果；这些操作是用户后续验收步骤，本次未执行。

1. 重复同一文件与规格：`calculations` 增量应为 0；观察 `cache_hits` 或 `persistent_hits`，区别 Redis 与 MySQL 索引复用。
2. `docker compose stop redis` 后再次请求旧规格，再请求新规格：旧结果可由 MySQL 索引复用；新规格需受限计算。`cache_errors` 应增加。`docker compose up -d redis` 后验证补缓存。
3. `docker compose exec redis redis-cli FLUSHDB` 只清除这个参考 Redis 的索引。再次请求旧规格应由 MySQL 回源，计算次数不应增加。该操作不能作为全新计算的基线。
4. 在一项任务为 processing 时执行 `docker compose kill -s SIGKILL app`，然后 `docker compose up -d app`；检查相同任务 ID 恢复到可终止状态，并验证输出。已经达到最多尝试次数的任务会 failed。若任务完成太快，应换成合法大图并在库中确认 processing 后再停止。
5. 用 `docker compose stop app`、`docker compose up -d app` 验证正常停止；用 `docker compose down`、`docker compose up --build -d` 验证容器重建但卷中数据保留。常规停止使用不带 `-v` 的 down，保留卷数据。
6. 测试数据库断连、恢复以及丢失事务回复：观察 worker 是否保留当前领取确认或结束写回的职责。SQL 测试覆盖 token 校验和恢复规则，网络回复丢失需要另行故障注入，不能只凭正常集成测试声称完成。

### 清理与保留策略

默认保留至少 30 天，按创建时间清理已终止任务和没有任务引用的旧结果；这是一项显式维护操作，不自动删除活跃任务，也不按 Redis TTL 删除文件。先停止 app，在持有同一目录锁与数据库锁的前提下预览：

```powershell
docker compose stop app
docker compose run --rm --no-deps --entrypoint /app/cleanup app -config /app/configs/config.yaml -days 30
```

确认预览符合自己的保留要求后，执行同一命令并加 `-apply`，再启动 app。数据库删除提交后才逐个删除已知文件；若文件删除失败，下次维护还能识别孤儿文件。清理 SQL、锁在容器卷上的行为和 apply 效果待真实验证。已有同步结果的创建时间不会因复用自动刷新，按最近使用时间保留需要新增字段和规则。

### 性能与 profiling

```powershell
go test ./internal/process -run '^$' -bench 'BenchmarkScratchReading|BenchmarkResize' -benchmem -benchtime=2s -count=5
go run ./cmd/loadtest -samples .runtime-data/samples -concurrency 4 -requests 32 -width 317

go tool pprof .runtime-data/cpu.pprof
```

第一轮是否需要计算必须用实际计数确认：以前处理过相同内容和规格时，MySQL 索引仍会复用。真正全新计算实验要选择从未处理过的内容/规格，且样本数至少等于请求数；热结果实验重复同一批输入；混合实验组合已处理和未处理规格。不同规格也要满足像素预算。

压测工具计时覆盖发出请求至读完响应，不包含构造 multipart 的时间；整个批次完成率包含失败请求，应同时查看失败率和状态分布。分位数按排序后 `floor((N-1)*p)` 取样，不等同于服务端阶段分位数。工具最大样本预读量 64 MiB、最多 512 文件、单文件 10 MiB；这些限制属于客户端工具。

package process

import (
	"bytes"
	"errors"
	"fmt"
	"image"
	_ "image/jpeg"
	_ "image/png"
)

var (
	ErrFileTooLarge = errors.New("file too large")
	ErrPixels       = errors.New("pixel budget exceeded")
	ErrDecode       = errors.New("invalid image")
	ErrFormat       = errors.New("unsupported or mismatched image format")
	ErrWidth        = errors.New("invalid target width")
	ErrOutput       = errors.New("encoded result too large")
)

type Limits struct {
	MaxFileBytes    int64 `yaml:"max_file_bytes"`
	MaxSourcePixels int64 `yaml:"max_source_pixels"`
	MaxOutputPixels int64 `yaml:"max_output_pixels"`
	MaxWidth        int   `yaml:"max_width"`
	MaxHeight       int   `yaml:"max_height"`
	MaxEncodedBytes int64 `yaml:"max_encoded_bytes"`
}

func CheckPixels(width, height int, budget int64) error {
	if width <= 0 || height <= 0 {
		return fmt.Errorf("%w: non-positive dimensions", ErrDecode)
	}
	if budget <= 0 || int64(width) > budget/int64(height) {
		return ErrPixels
	}
	return nil
}

func Inspect(data []byte, limits Limits) (image.Config, string, error) {
	if int64(len(data)) > limits.MaxFileBytes {
		return image.Config{}, "", ErrFileTooLarge
	}
	cfg, format, err := image.DecodeConfig(bytes.NewReader(data))
	if err != nil {
		return image.Config{}, "", fmt.Errorf("%w: %w", ErrDecode, err)
	}
	if format != "jpeg" && format != "png" {
		return image.Config{}, "", ErrFormat
	}
	if err := CheckPixels(cfg.Width, cfg.Height, limits.MaxSourcePixels); err != nil {
		return image.Config{}, "", err
	}
	return cfg, format, nil
}

package admission

import (
	"context"
	"fmt"
	"sync"

	"image-processor-reference/internal/core"
)

type Gate struct{ running, admitted chan struct{} }

func New(parallel, waiting int) (*Gate, error) {
	if parallel <= 0 || waiting < 0 || waiting > 10000 || parallel > 10000 {
		return nil, fmt.Errorf("invalid gate capacity")
	}
	return &Gate{make(chan struct{}, parallel), make(chan struct{}, parallel+waiting)}, nil
}

func (g *Gate) Acquire(ctx context.Context) (func(), error) {
	if err := ctx.Err(); err != nil {
		return nil, err
	}
	select {
	case g.admitted <- struct{}{}:
	default:
		return nil, core.ErrBusy
	}
	select {
	case g.running <- struct{}{}:
		if err := ctx.Err(); err != nil {
			<-g.running
			<-g.admitted
			return nil, err
		}
		var once sync.Once
		return func() { once.Do(func() { <-g.running; <-g.admitted }) }, nil
	case <-ctx.Done():
		<-g.admitted
		return nil, ctx.Err()
	}
}

func (g *Gate) Snapshot() (running, waiting int) {
	running = len(g.running)
	waiting = len(g.admitted) - running
	if waiting < 0 {
		waiting = 0
	}
	return
}

import (
	"bytes"
	"context"

	"image/jpeg"
	"image/png"

	"image-processor-reference/internal/admission"

type Service struct {
	Limits  Limits
	Gate    *admission.Gate
	Metrics *observe.Metrics
}

type boundedBuffer struct {
	buffer bytes.Buffer
	limit  int64
}

func (b *boundedBuffer) Write(data []byte) (int, error) {
	if int64(len(data)) > b.limit-int64(b.buffer.Len()) {
		return 0, ErrOutput
	}
	return b.buffer.Write(data)
}

// Deliberately expose only Write to encoders: embedded WriteByte/WriteString would bypass the budget.
func (b *boundedBuffer) Bytes() []byte { return b.buffer.Bytes() }
func (b *boundedBuffer) Len() int      { return b.buffer.Len() }

func (s *Service) Resize(ctx context.Context, data []byte, spec core.Spec) ([]byte, core.Result, error) {
	if err := ctx.Err(); err != nil {
		return nil, core.Result{}, err
	}
	done := observe.Span(ctx, "wait_compute")
	release, err := s.Gate.Acquire(ctx)
	done()
	if err != nil {
		return nil, core.Result{}, err
	}
	defer release()
	done = observe.Span(ctx, "inspect")
	cfg, _, err := Inspect(data, s.Limits)
	done()
	if err != nil {
		return nil, core.Result{}, err
	}
	width, height, err := TargetSize(cfg.Width, cfg.Height, spec.Width, s.Limits)
	if err != nil {
		return nil, core.Result{}, err
	}
	if spec.Format != "png" && spec.Format != "jpeg" {
		return nil, core.Result{}, ErrFormat
	}
	if err := ctx.Err(); err != nil {
		return nil, core.Result{}, err
	}
	s.Metrics.Calculations.Add(1)
	done = observe.Span(ctx, "decode")
	source, _, err := image.Decode(bytes.NewReader(data))
	done()
	if err != nil {
		return nil, core.Result{}, ErrDecode
	}
	if source.Bounds().Dx() != cfg.Width || source.Bounds().Dy() != cfg.Height {
		return nil, core.Result{}, ErrDecode
	}
	if err := ctx.Err(); err != nil {
		return nil, core.Result{}, err
	}
	target := image.NewRGBA(image.Rect(0, 0, width, height))
	done = observe.Span(ctx, "scale")
	draw.BiLinear.Scale(target, target.Bounds(), source, source.Bounds(), draw.Src, nil)
	done()
	if err := ctx.Err(); err != nil {
		return nil, core.Result{}, err
	}
	output := boundedBuffer{limit: s.Limits.MaxEncodedBytes}
	done = observe.Span(ctx, "encode")
	if spec.Format == "png" {
		err = png.Encode(&output, target)
	} else {
		err = jpeg.Encode(&output, target, &jpeg.Options{Quality: 85})
	}
	done()
	if err != nil {
		return nil, core.Result{}, err
	}
	if err := ctx.Err(); err != nil {
		return nil, core.Result{}, err
	}
	return output.Bytes(), core.Result{Width: width, Height: height, Format: spec.Format, Bytes: int64(output.Len())}, nil
}

	ShutdownSeconds int            `yaml:"shutdown_seconds"`
	CacheSeconds    int            `yaml:"cache_seconds"`
	CacheEnabled    bool           `yaml:"cache_enabled"`
	PoolEnabled     bool           `yaml:"pool_enabled"`
	Limits          process.Limits `yaml:"limits"`
}

func (c Config) Timeout() time.Duration { return time.Duration(c.ProcessSeconds) * time.Second }
func (c Config) ShutdownTimeout() time.Duration {
	return time.Duration(c.ShutdownSeconds) * time.Second
}

func Load(path string) (Config, error) {
	data, err := os.ReadFile(path)
	if err != nil {
		return Config{}, err
	}
	var c Config
	decoder := yaml.NewDecoder(bytes.NewReader(data))
	decoder.KnownFields(true)
	if err := decoder.Decode(&c); err != nil {
		return c, err
	}
	for key, target := range map[string]*string{"SERVER_ADDR": &c.Addr, "MYSQL_DSN": &c.DSN, "REDIS_ADDR": &c.RedisAddr, "DATA_ROOT": &c.DataRoot} {
		if value, ok := os.LookupEnv(key); ok {
			*target = value
		}
	}
	if value, ok := os.LookupEnv("CACHE_ENABLED"); ok {
		c.CacheEnabled, err = strconv.ParseBool(value)
		if err != nil {
			return c, err
		}
	}
	return c, c.Validate()
}

func (c Config) Validate() error {
	if c.Addr == "" || c.DSN == "" || c.DataRoot == "" {
		return fmt.Errorf("addr, mysql_dsn and data_root are required")
	}
	if c.MaxRequestBytes <= c.Limits.MaxFileBytes || c.MaxRequestBytes > 64<<20 || c.Limits.MaxFileBytes <= 0 {
		return fmt.Errorf("invalid byte limits")
	}
	if c.Limits.MaxSourcePixels <= 0 || c.Limits.MaxSourcePixels > 100_000_000 || c.Limits.MaxOutputPixels <= 0 || c.Limits.MaxOutputPixels > 16_000_000 {
		return fmt.Errorf("invalid pixel limits")
	}
	if c.Limits.MaxWidth < 10 || c.Limits.MaxWidth > 8192 || c.Limits.MaxHeight <= 0 || c.Limits.MaxHeight > 8192 || c.Limits.MaxEncodedBytes <= 0 || c.Limits.MaxEncodedBytes > 64<<20 {
		return fmt.Errorf("invalid output limits")
	}
	if c.Parallel <= 0 || c.Parallel > 64 || c.Waiting < 0 || c.Waiting > 256 || c.MaxRequests <= 0 || c.MaxRequests > 256 || c.MaxUploads <= 0 || c.MaxUploads > c.MaxRequests {
		return fmt.Errorf("invalid admission limits")
	}
	if c.Workers <= 0 || c.Workers > 64 || c.Backlog < c.Workers || c.Backlog > 10000 || c.MaxSpecs <= 0 || c.MaxSpecs > 8 {
		return fmt.Errorf("invalid job limits")
	}

		return fmt.Errorf("invalid time/retry limits")
	}
	if c.CacheEnabled && c.RedisAddr == "" {
		return fmt.Errorf("redis_addr required when cache is enabled")
	}
	return nil
}

目录内核锁与数据库命名锁共同约束这份单实例方案；数据库连接断开后命名锁会丢失，不能单独用它证明旧进程已退出。该方案要求同数据库始终配同一个专属数据根目录。真正的迁移、读写、重连仍待独立 MySQL 验证；测试入口在 P02。参考 [Go 数据库取消](https://go.dev/doc/database/cancel-operations)。

func Open(ctx context.Context, dsn string, capacity int) (*Repository, error) {
	cfg, err := mysql.ParseDSN(dsn)
	if err != nil {
		return nil, err
	}
	cfg.ParseTime = true
	cfg.Loc = time.UTC
	cfg.MultiStatements = true
	cfg.Timeout = 2 * time.Second
	cfg.ReadTimeout = 3 * time.Second
	cfg.WriteTimeout = 3 * time.Second
	if cfg.Params == nil {
		cfg.Params = map[string]string{}
	}
	cfg.Params["time_zone"] = "'+00:00'"
	db, err := sql.Open("mysql", cfg.FormatDSN())
	if err != nil {
		return nil, err
	}
	db.SetMaxOpenConns(16)
	db.SetMaxIdleConns(8)
	db.SetConnMaxLifetime(5 * time.Minute)
	if err := db.PingContext(ctx); err != nil {
		db.Close()
		return nil, err
	}
	return &Repository{DB: db, Capacity: capacity}, nil
}

// Keep this connection for the whole process: only one service OR maintenance tool may own the data.
func (r *Repository) Lock(ctx context.Context) (func(), error) {
	conn, err := r.DB.Conn(ctx)
	if err != nil {
		return nil, err
	}
	var owned int
	if err := conn.QueryRowContext(ctx, "SELECT GET_LOCK('image-processor-reference:v1', 0)").Scan(&owned); err != nil || owned != 1 {
		conn.Close()
		if err != nil {
			return nil, err
		}
		return nil, fmt.Errorf("another service or maintenance process is running")
	}
	return func() {
		ctx, cancel := context.WithTimeout(context.Background(), time.Second)
		defer cancel()
		_, _ = conn.ExecContext(ctx, "SELECT RELEASE_LOCK('image-processor-reference:v1')")
		_ = conn.Close()
	}, nil
}

func (r *Repository) Migrate(ctx context.Context) error {
	_, err := r.DB.ExecContext(ctx, "CREATE TABLE IF NOT EXISTS schema_migrations (version INT PRIMARY KEY, checksum CHAR(64) NOT NULL, applied_at DATETIME(6) NOT NULL DEFAULT CURRENT_TIMESTAMP(6))")
	if err != nil {
		return err
	}
	files, err := migrations.ReadDir("migrations")
	if err != nil {
		return err
	}
	sort.Slice(files, func(i, j int) bool { return files[i].Name() < files[j].Name() })
	for _, file := range files {
		version, err := strconv.Atoi(strings.SplitN(file.Name(), "_", 2)[0])
		if err != nil {
			return err
		}
		data, err := migrations.ReadFile("migrations/" + file.Name())
		if err != nil {
			return err
		}
		sum := sha256.Sum256(data)
		checksum := hex.EncodeToString(sum[:])
		var applied string
		err = r.DB.QueryRowContext(ctx, "SELECT checksum FROM schema_migrations WHERE version=?", version).Scan(&applied)
		if err == nil {
			if applied != checksum {
				return fmt.Errorf("migration %d checksum changed", version)
			}
			continue
		}
		if !errors.Is(err, sql.ErrNoRows) {
			return err
		}
		// MySQL DDL may commit implicitly. This initial script uses idempotent CREATE statements so partial initialization is resumable.
		if _, err := r.DB.ExecContext(ctx, string(data)); err != nil {
			return err
		}
		if _, err := r.DB.ExecContext(ctx, "INSERT INTO schema_migrations(version,checksum) VALUES(?,?)", version, checksum); err != nil {
			return err
		}
	}
	return nil
}

	for _, item := range items {
		switch item.State {
		case "processing":
			active = true
		case "succeeded":
			succeeded = true
		case "failed":
			failed = true
		}
	}
	for _, item := range items {
		if item.State == "pending" {
			if active || succeeded || failed {
				return "processing"
			}
			return "pending"
		}
	}
	if active {
		return "processing"
	}
	if failed {
		return "failed"
	}
	if succeeded {
		return "succeeded"
	}
	return "pending"
}

func (s *Server) fail(w http.ResponseWriter, err error) {
	status, message := 500, "internal server error"
	switch {
	case errors.Is(err, core.ErrBusy):
		status, message = 503, "service capacity exhausted"
		s.Metrics.Rejected.Add(1)
		w.Header().Set("Retry-After", "1")
	case errors.Is(err, context.DeadlineExceeded):
		status, message = 504, "processing timeout"
	case errors.Is(err, context.Canceled):
		status, message = 408, "request canceled"
	case errors.Is(err, process.ErrFileTooLarge), errors.Is(err, process.ErrOutput), errors.Is(err, process.ErrPixels):
		status, message = 413, "image resource budget exceeded"
	case errors.Is(err, process.ErrDecode):
		status, message = 422, "invalid image"
	case errors.Is(err, process.ErrFormat):
		status, message = 415, "unsupported or mismatched image format"
	case errors.Is(err, process.ErrWidth):
		status, message = 400, "invalid target width"
	case errors.Is(err, core.ErrNotFound):
		status, message = 404, "not found"
	case errors.Is(err, core.ErrNotReady):
		status, message = 409, "result not ready"
	case errors.Is(err, os.ErrNotExist):
		status, message = 410, "result file unavailable"
	}
	if status == 500 {
		slog.Error("request", "error", err)
	}
	jsonResponse(w, status, map[string]string{"error": message})

func (s *Server) upload(w http.ResponseWriter, r *http.Request) ([]byte, image.Config, string, bool) {
	release, err := s.Uploads.Acquire(r.Context())
	if err != nil {
		s.fail(w, err)
		return nil, image.Config{}, "", false
	}
	defer release()
	if r.ContentLength > s.Config.MaxRequestBytes {
		jsonResponse(w, 413, map[string]string{"error": "request body too large"})
		return nil, image.Config{}, "", false
	}
	r.Body = http.MaxBytesReader(w, r.Body, s.Config.MaxRequestBytes)
	done := observe.Span(r.Context(), "multipart")
	err = r.ParseMultipartForm(2 << 20)
	done()
	if r.MultipartForm != nil {
		defer r.MultipartForm.RemoveAll()
	}
	if err != nil {
		var tooLarge *http.MaxBytesError
		status := 400
		if errors.As(err, &tooLarge) {
			status = 413
		}
		jsonResponse(w, status, map[string]string{"error": "invalid or oversized multipart body"})
		return nil, image.Config{}, "", false
	}
	file, header, err := r.FormFile("file")
	if err != nil {
		jsonResponse(w, 400, map[string]string{"error": "file is required"})
		return nil, image.Config{}, "", false
	}
	defer file.Close()
	declared, _, err := mime.ParseMediaType(header.Header.Get("Content-Type"))
	if err != nil || (declared != "image/png" && declared != "image/jpeg") {
		s.fail(w, process.ErrFormat)
		return nil, image.Config{}, "", false
	}
	done = observe.Span(r.Context(), "read_input")
	data, err := s.Readers.Read(r.Context(), file, s.Config.Limits.MaxFileBytes, s.Config.PoolEnabled)
	done()
	if err != nil {
		s.fail(w, err)
		return nil, image.Config{}, "", false
	}
	cfg, actual, err := process.Inspect(data, s.Config.Limits)
	if err != nil {
		s.fail(w, err)
		return nil, image.Config{}, "", false
	}
	if declared != "image/"+actual {
		s.fail(w, process.ErrFormat)
		return nil, image.Config{}, "", false
	}
	return data, cfg, actual, true
}

func (s *Server) submit(w http.ResponseWriter, r *http.Request) {
	data, cfg, actual, ok := s.upload(w, r)
	if !ok {
		return
	}
	text := r.FormValue("specs")
	if text == "" || len(text) > 4096 {
		jsonResponse(w, 400, map[string]string{"error": "specs JSON is required, maximum 4096 bytes"})
		return
	}
	var specs []core.Spec
	if err := json.Unmarshal([]byte(text), &specs); err != nil || len(specs) == 0 || len(specs) > s.Config.MaxSpecs {
		jsonResponse(w, 400, map[string]string{"error": "invalid specs count or JSON"})
		return
	}
	seen := map[core.Spec]bool{}
	for i := range specs {
		if specs[i].Format == "" {
			specs[i].Format = actual
		}
		if seen[specs[i]] {
			jsonResponse(w, 400, map[string]string{"error": "duplicate spec"})
			return
		}
		seen[specs[i]] = true
		if err := s.validate(cfg, specs[i]); err != nil {
			s.fail(w, err)
			return
		}
	}
	id, err := core.NewID()
	if err != nil {
		s.fail(w, err)
		return
	}
	path := "sources/" + id
	ctx, cancel := context.WithTimeout(r.Context(), s.Config.Timeout())
	defer cancel()
	if err := s.Files.Publish(ctx, path, data); err != nil {
		s.fail(w, err)
		return
	}
	err = s.Repository.Create(ctx, id, path, cache.SourceHash(data), specs)
	if err != nil {
		// Commit errors can mean the reply was lost after commit. Only delete when a fresh query confirms absence.
		checkCtx, finish := context.WithTimeout(context.Background(), 2*time.Second)
		exists, checkErr := s.Repository.Exists(checkCtx, id)
		finish()
		if checkErr == nil && !exists {
			_ = s.Files.Remove(path)
		}
		s.fail(w, err)
		return
	}
	w.Header().Set("Location", "/jobs/"+id)
	jsonResponse(w, 202, map[string]string{"job_id": id, "status_url": "/jobs/" + id})

### A02：固定 worker 与原子领取

**实现前先过一遍当前流程：** 讲一次 A01 的源文件/事务/202/query，确认此时记录存在并不表示计算完成；下载的成功路径从本章开始联调。

每个固定 worker 以短事务选择到期 pending，FOR UPDATE SKIP LOCKED 跳过别人已锁的候选项；写 processing、attempts+1、随机 token 后提交，CPU 计算在事务外进行。无任务时等待 200ms，避免空转。由于查询 JOIN jobs，锁的范围不能想当然只理解成 items 一行；同 job 的不同规格可能短暂串行领取，但不会因此重复拥有同一规格。

COMMIT 报错可能已成功，worker 使用新连接 VerifyClaim 校验同 token 是否 processing；数据库不可用时保留该 worker 直到能确认或服务退出，避免把已领取的任务遗弃。临时失败和最终状态写回的处理见下一章。

SQL 采用 MySQL 8.4 InnoDB。该方案是单实例、有固定 worker 和有界积压的执行；不宣称单条任务全生命周期只执行一次。锁语义参考 [MySQL 锁定读取](https://dev.mysql.com/doc/refman/8.4/en/innodb-locking-reads.html)。代码已编译，真实并发领取仍待执行。

	"context"

func (r *Repository) Claim(ctx context.Context) (core.Item, error) {
	tx, err := r.DB.BeginTx(ctx, &sql.TxOptions{Isolation: sql.LevelReadCommitted})
	if err != nil {
		return core.Item{}, err
	}
	defer tx.Rollback()
	var item core.Item
	err = tx.QueryRowContext(ctx, "SELECT i.id,i.job_id,i.width,i.format,i.attempts,j.source_path,j.source_hash FROM items i JOIN jobs j ON j.id=i.job_id WHERE i.state='pending' AND i.next_at<=UTC_TIMESTAMP(6) ORDER BY i.next_at,i.id LIMIT 1 FOR UPDATE SKIP LOCKED").Scan(&item.ID, &item.JobID, &item.Width, &item.Format, &item.Attempts, &item.SourcePath, &item.SourceHash)
	if errors.Is(err, sql.ErrNoRows) {
		return item, core.ErrNotFound
	}
	if err != nil {
		return item, err
	}
	item.Token, err = core.NewID()
	if err != nil {
		return item, err
	}
	result, err := tx.ExecContext(ctx, "UPDATE items SET state='processing',attempts=attempts+1,attempt_token=?,updated_at=UTC_TIMESTAMP(6) WHERE id=? AND state='pending'", item.Token, item.ID)
	if err != nil {
		return item, err
	}
	count, err := result.RowsAffected()
	if err != nil {
		return item, err
	}
	if count != 1 {
		return item, core.ErrStale
	}
	item.Attempts++
	item.State = "processing"
	if err := tx.Commit(); err != nil {
		return item, err // The worker must verify this token on a fresh connection before abandoning ownership.
	}
	return item, nil
}

// VerifyClaim resolves an ambiguous claim commit without resetting another attempt.
func (r *Repository) VerifyClaim(ctx context.Context, item core.Item) (core.Item, bool, error) {
	var state string
	var token sql.NullString
	err := r.DB.QueryRowContext(ctx, "SELECT state,attempt_token,attempts FROM items WHERE id=?", item.ID).Scan(&state, &token, &item.Attempts)
	if errors.Is(err, sql.ErrNoRows) {
		return item, false, nil
	}
	if err != nil {
		return item, false, err
	}
	item.State = state
	return item, state == "processing" && token.Valid && token.String == item.Token, nil
}

type Workers struct {
	Repository         *repository.Repository
	Resolver           *cache.Resolver
	Files              *storage.Store
	Metrics            *observe.Metrics
	Count, MaxAttempts int
	Timeout            time.Duration
	wg                 sync.WaitGroup
}

func (w *Workers) Start(ctx context.Context) {
	for range w.Count {
		w.wg.Add(1)
		go func() { defer w.wg.Done(); w.run(ctx) }()
	}
}
func (w *Workers) Wait(ctx context.Context) error {
	done := make(chan struct{})
	go func() { w.wg.Wait(); close(done) }()
	select {
	case <-done:
		return nil
	case <-ctx.Done():
		return ctx.Err()
	}
}
func (w *Workers) pause(ctx context.Context) bool {
	timer := time.NewTimer(200 * time.Millisecond)
	defer timer.Stop()
	select {
	case <-ctx.Done():
		return false
	case <-timer.C:
		return true
	}
}
func (w *Workers) run(root context.Context) {
	for root.Err() == nil {
		ctx, cancel := context.WithTimeout(root, 2*time.Second)
		item, err := w.Repository.Claim(ctx)
		cancel()
		if err != nil && item.ID != "" && item.Token != "" {
			// A lost COMMIT reply can leave a task processing. Retain this worker until ownership is known.
			for root.Err() == nil {
				check, finish := context.WithTimeout(root, 2*time.Second)
				verified, owned, checkErr := w.Repository.VerifyClaim(check, item)
				finish()
				if checkErr == nil {
					if owned {
						item, err = verified, nil
					}
					break
				}
				if !w.pause(root) {
					return
				}
			}
		}
		if err != nil {
			if !errors.Is(err, core.ErrNotFound) && root.Err() == nil {
				slog.Error("claim", "error", err)
			}
			if !w.pause(root) {
				return
			}
			continue
		}
		ctx, cancel = context.WithTimeout(observe.WithID(root, item.ID), w.Timeout)
		data, err := w.Files.Read(item.SourcePath, w.Resolver.Processor.Limits.MaxFileBytes)
		if err == nil && cache.SourceHash(data) != item.SourceHash {
			err = process.ErrDecode
		}
		var result core.Result
		if err == nil {
			result, err = w.Resolver.Resolve(ctx, root, data, item.Spec)
		}
		cancel()
		if root.Err() != nil {
			return
		} // Leave processing for the next single-instance startup recovery.
		cause := err
		if cause != nil {
			w.Metrics.WorkerFailures.Add(1)
			slog.Error("attempt", "item_id", item.ID, "attempt", item.Attempts, "error", cause)
		}
		permanent := errors.Is(cause, process.ErrDecode) || errors.Is(cause, process.ErrPixels) || errors.Is(cause, process.ErrWidth) || errors.Is(cause, process.ErrFormat) || errors.Is(cause, process.ErrFileTooLarge) || errors.Is(cause, process.ErrOutput) || errors.Is(cause, os.ErrNotExist)
		// If the DB is unavailable, retain this bounded worker's ownership until the status write succeeds or the process stops.
		for root.Err() == nil {
			finalCtx, finish := context.WithTimeout(root, 2*time.Second)
			if cause == nil {

				break
			}
			slog.Error("finish", "item_id", item.ID, "error", err)
			if !w.pause(root) {
				return
			}
		}
	}
}

### A03：重试、发布、恢复与清理

**实现前先过一遍当前流程：** 按领取 → 读取源 → 处理 → 发布文件 → 存结果索引 → 成功状态走一次，在每一步标出崩溃后可能留下的文件/记录。

临时失败按 2、4…秒退避，最多默认 3 次；输入损坏、尺寸/格式超限和源文件不存在直接终止。Complete/Fail 以 processing + token 做条件写，旧尝试不能覆盖新尝试。状态写入暂时失败时，当前 worker 保留结束写回职责；不能只记日志后去拿下一项。

源/结果先写同目录临时文件、Sync、关闭，再 Rename。结果键对应不变的内容/规格/算法版本，重复生成允许相同文件重用。SQL 和文件没有跨资源原子事务：提交返回错误时用新连接查证，无法确认时保留文件；维护再清理旧孤儿。此实现针对进程重启，不承诺断电、磁盘损坏或 DB/文件跨资源事务原子性。

import (
	"context"
	"database/sql"
	"image-processor-reference/internal/core"
	"time"

func (r *Repository) Complete(ctx context.Context, item core.Item, key string) error {
	result, err := r.DB.ExecContext(ctx, "UPDATE items SET state='succeeded',result_key=?,error_message='',attempt_token=NULL,updated_at=UTC_TIMESTAMP(6) WHERE id=? AND state='processing' AND attempt_token=?", key, item.ID, item.Token)
	return owns(result, err)
}

func (r *Repository) Fail(ctx context.Context, item core.Item, permanent bool, maxAttempts int) error {
	state, message := "pending", "temporary processing failure"
	if permanent || item.Attempts >= maxAttempts {
		state = "failed"
		message = "processing failed after retry policy"
	}
	delay := 1 << min(item.Attempts, 5)
	result, err := r.DB.ExecContext(ctx, "UPDATE items SET state=?,error_message=?,attempt_token=NULL,next_at=DATE_ADD(UTC_TIMESTAMP(6),INTERVAL ? SECOND),updated_at=UTC_TIMESTAMP(6) WHERE id=? AND state='processing' AND attempt_token=?", state, message, delay, item.ID, item.Token)
	return owns(result, err)
}

func owns(result sql.Result, err error) error {
	if err != nil {
		return err
	}
	count, err := result.RowsAffected()
	if err != nil {
		return err
	}
	if count != 1 {

	_, err := r.DB.ExecContext(ctx, "UPDATE items SET state=IF(attempts>=?,'failed','pending'),error_message='previous process interrupted',attempt_token=NULL,next_at=UTC_TIMESTAMP(6),updated_at=UTC_TIMESTAMP(6) WHERE state='processing'", maxAttempts)
	return err
}

	if err != nil {
		return nil, err
	}
	defer tx.Rollback()
	paths := []string{}
	rows, err := tx.QueryContext(ctx, "SELECT source_path FROM jobs j WHERE created_at<? AND NOT EXISTS(SELECT 1 FROM items i WHERE i.job_id=j.id AND i.state IN ('pending','processing'))", cutoff)
	if err != nil {
		return nil, err
	}

		var path string
		if err := rows.Scan(&path); err != nil {
			rows.Close()
			return nil, err
		}
		paths = append(paths, path)
	}
	err = rows.Err()
	rows.Close()
	if err != nil {
		return nil, err
	}
	if apply {
		if _, err = tx.ExecContext(ctx, "DELETE FROM jobs WHERE created_at<? AND NOT EXISTS(SELECT 1 FROM items WHERE items.job_id=jobs.id AND items.state IN ('pending','processing'))", cutoff); err != nil {
			return nil, err
		}

	rows, err = tx.QueryContext(ctx, "SELECT path FROM results r WHERE created_at<? AND NOT EXISTS(SELECT 1 FROM items i JOIN jobs j ON j.id=i.job_id WHERE i.result_key=r.result_key AND (j.created_at>=? OR EXISTS(SELECT 1 FROM items active WHERE active.job_id=j.id AND active.state IN ('pending','processing'))))", cutoff, cutoff)
	if err != nil {
		return nil, err
	}
	for rows.Next() {
		var path string
		if err := rows.Scan(&path); err != nil {
			rows.Close()
			return nil, err
		}
		paths = append(paths, path)
	}
	err = rows.Err()
	rows.Close()

			return nil, err

		err = tx.Commit()

type Results interface {
	Result(context.Context, string) (core.Result, error)
	SaveResult(context.Context, core.Result) error
}

type Resolver struct {
	Repository   Results
	Index        Index
	Files        *storage.Store
	Processor    *process.Service
	Metrics      *observe.Metrics
	Timeout, TTL time.Duration
	Work         *admission.Gate
	group        singleflight.Group
	workMu       sync.Mutex
	closing      bool
	active       sync.WaitGroup
}

func (r *Resolver) valid(result core.Result, key string, spec core.Spec) bool {
	limits := r.Processor.Limits
	return result.Key == key && result.Width == spec.Width && result.Format == spec.Format && result.Height > 0 && result.Height <= limits.MaxHeight && result.Bytes <= limits.MaxEncodedBytes && process.CheckPixels(result.Width, result.Height, limits.MaxOutputPixels) == nil && result.Path == storage.ResultPath(key, spec.Format) && r.Files.Valid(result.Path, result.Bytes)
}

func (r *Resolver) put(ctx context.Context, result core.Result) {
	if r.Index == nil {
		return
	}
	// +-10% TTL jitter. The key still identifies an immutable processing result.
	ttl := r.TTL + time.Duration((rand.Float64()*0.2-0.1)*float64(r.TTL))
	if err := r.Index.Put(ctx, result, ttl); err != nil {
		r.Metrics.CacheErrors.Add(1)
	}
}

func (r *Resolver) resolve(ctx context.Context, key string, data []byte, spec core.Spec) (core.Result, error) {
	if r.Index != nil {
		done := observe.Span(ctx, "redis_lookup")
		result, hit, err := r.Index.Get(ctx, key)
		done()
		result.Path = storage.ResultPath(key, spec.Format)
		if err != nil {
			r.Metrics.CacheErrors.Add(1)
		} else if hit && r.valid(result, key, spec) {
			r.Metrics.CacheHits.Add(1)
			return result, nil
		} else {
			r.Metrics.CacheMisses.Add(1)
			if hit {
				if err := r.Index.Delete(ctx, key); err != nil {
					r.Metrics.CacheErrors.Add(1)
				}
			}
		}
	}
	done := observe.Span(ctx, "persistent_lookup")
	lookupCtx, cancel := context.WithTimeout(ctx, 2*time.Second)
	result, err := r.Repository.Result(lookupCtx, key)
	cancel()
	done()
	if err == nil && r.valid(result, key, spec) {
		r.Metrics.DBHits.Add(1)
		r.put(ctx, result)
		return result, nil
	}
	if err != nil && !errors.Is(err, core.ErrNotFound) {
		return core.Result{}, err
	}
	encoded, result, err := r.Processor.Resize(ctx, data, spec)
	if err != nil {
		return core.Result{}, err
	}
	result.Key = key
	result.Path = storage.ResultPath(key, spec.Format)
	done = observe.Span(ctx, "publish_result")
	err = r.Files.Publish(ctx, result.Path, encoded)
	done()
	if err != nil {
		return core.Result{}, err
	}
	if err := ctx.Err(); err != nil {
		return core.Result{}, err
	}
	saveCtx, cancel := context.WithTimeout(ctx, 2*time.Second)
	done = observe.Span(ctx, "persist_result")
	err = r.Repository.SaveResult(saveCtx, result)
	cancel()
	done()
	if err != nil {
		return core.Result{}, err
	}
	r.put(ctx, result)
	return result, nil

import (
	"context"

// waitCtx cancels this caller's wait. workParent is the service lifecycle, never a client request.
func (r *Resolver) Resolve(waitCtx, workParent context.Context, data []byte, spec core.Spec) (core.Result, error) {
	if err := waitCtx.Err(); err != nil {
		return core.Result{}, err
	}
	key := Key(data, spec)
	id := observe.ID(waitCtx)
	channel := r.group.DoChan(key, func() (any, error) {
		r.workMu.Lock()
		if r.closing {
			r.workMu.Unlock()
			return nil, context.Canceled
		}
		r.active.Add(1)
		r.workMu.Unlock()
		defer r.active.Done()
		ctx, cancel := context.WithTimeout(observe.WithID(workParent, id), r.Timeout)
		defer cancel()
		release, err := r.Work.Acquire(ctx)
		if err != nil {
			return nil, err
		}
		defer release()
		return r.resolve(ctx, key, data, spec)
	})
	select {
	case <-waitCtx.Done():
		return core.Result{}, waitCtx.Err()
	case answer := <-channel:
		if answer.Shared {
			r.Metrics.Shared.Add(1)
		}
		if answer.Err != nil {
			return core.Result{}, answer.Err
		}
		return answer.Val.(core.Result), nil
	}
}

// Call after canceling the service context. Wait for shared CPU work as well as HTTP and workers.
func (r *Resolver) Shutdown(ctx context.Context) error {
	r.workMu.Lock()
	r.closing = true
	r.workMu.Unlock()
	done := make(chan struct{})
	go func() { r.active.Wait(); close(done) }()
	select {
	case <-done:
		return nil
	case <-ctx.Done():
		return ctx.Err()
	}
}

package process

import (
	"bytes"
	"context"
	"io"

	"image-processor-reference/internal/observe"
)

const chunkSize = 32 << 10

// The channel bounds retained scratch buffers. Returned image bytes have independent ownership.
type ReaderPool struct {
	free    chan []byte
	metrics *observe.Metrics
}

func NewReaderPool(retained int, metrics *observe.Metrics) *ReaderPool {
	return &ReaderPool{make(chan []byte, retained), metrics}
}

func (p *ReaderPool) Read(ctx context.Context, reader io.Reader, limit int64, enabled bool) ([]byte, error) {
	var scratch []byte
	if enabled {
		select {
		case scratch = <-p.free:
			p.metrics.PoolHits.Add(1)
		default:
		}
	}
	if scratch == nil {
		scratch = make([]byte, chunkSize)
		p.metrics.PoolNew.Add(1)
	}
	if enabled {
		defer func() {
			select {
			case p.free <- scratch:
			default:
				p.metrics.PoolDrops.Add(1)
			}
		}()
	}
	var output bytes.Buffer
	limited := io.LimitReader(reader, limit+1)
	for {
		if err := ctx.Err(); err != nil {
			return nil, err
		}
		n, err := limited.Read(scratch)
		if n > 0 {
			if int64(output.Len())+int64(n) > limit {
				return nil, ErrFileTooLarge
			}
			_, _ = output.Write(scratch[:n])
		}
		if err == io.EOF {
			break
		}
		if err != nil {
			return nil, err
		}
		if n == 0 {
			return nil, io.ErrNoProgress
		}
	}
	return output.Bytes(), nil
}

func main() {
	path := flag.String("config", "configs/config.yaml", "config path")
	debugAddr := flag.String("debug", "", "optional pprof address")
	flag.Parse()
	slog.SetDefault(slog.New(slog.NewJSONHandler(os.Stdout, nil)))
	cfg, err := config.Load(*path)
	if err != nil {
		fatal(err)
	}
	files, err := storage.New(cfg.DataRoot)
	if err != nil {
		fatal(err)
	}
	unlockFiles, err := files.Lock()
	if err != nil {
		fatal(err)
	}
	defer unlockFiles()
	root, cancel := context.WithCancel(context.Background())
	defer cancel()
	startup, stopStartup := context.WithTimeout(root, 20*time.Second)
	repo, err := repository.Open(startup, cfg.DSN, cfg.Backlog)
	if err != nil {
		fatal(err)
	}
	defer repo.DB.Close()
	unlock, err := repo.Lock(startup)
	if err != nil {
		fatal(err)
	}
	defer unlock()
	if err := repo.Migrate(startup); err != nil {
		fatal(err)
	}
	if err := repo.Recover(startup, cfg.MaxAttempts); err != nil {
		fatal(err)
	}
	stopStartup()
	metrics := &observe.Metrics{}
	compute, err := admission.New(cfg.Parallel, cfg.Waiting)
	if err != nil {
		fatal(err)
	}
	requests, err := admission.New(cfg.MaxRequests, 0)
	if err != nil {
		fatal(err)
	}
	uploads, err := admission.New(cfg.MaxUploads, 0)
	if err != nil {
		fatal(err)
	}
	work, err := admission.New(cfg.MaxRequests+cfg.Workers, 0)
	if err != nil {
		fatal(err)
	}
	processor := &process.Service{Limits: cfg.Limits, Gate: compute, Metrics: metrics}
	resolver := &cache.Resolver{Repository: repo, Files: files, Processor: processor, Metrics: metrics, Timeout: cfg.Timeout(), TTL: time.Duration(cfg.CacheSeconds) * time.Second, Work: work}
	if cfg.CacheEnabled {
		index := cache.NewRedis(cfg.RedisAddr)
		defer index.Client.Close()
		resolver.Index = index
	}
	workers := &jobs.Workers{Repository: repo, Resolver: resolver, Files: files, Metrics: metrics, Count: cfg.Workers, MaxAttempts: cfg.MaxAttempts, Timeout: cfg.Timeout()}
	workers.Start(root)
	api := &httpapi.Server{Config: cfg, Repository: repo, Resolver: resolver, Files: files, Readers: process.NewReaderPool(cfg.MaxUploads, metrics), Metrics: metrics, Requests: requests, Uploads: uploads}
	server := &http.Server{Addr: cfg.Addr, Handler: api.Routes(root), ReadHeaderTimeout: 5 * time.Second, ReadTimeout: 30 * time.Second, WriteTimeout: 60 * time.Second, IdleTimeout: 120 * time.Second, BaseContext: func(net.Listener) context.Context { return root }}
	go func() {
		if err := server.ListenAndServe(); err != nil && err != http.ErrServerClosed {
			fatal(err)
		}
	}()
	var debug *http.Server
	if *debugAddr != "" {
		debug = &http.Server{Addr: *debugAddr, Handler: http.DefaultServeMux, ReadHeaderTimeout: 5 * time.Second}
		go func() {
			if err := debug.ListenAndServe(); err != nil && err != http.ErrServerClosed {
				fatal(err)
			}
		}()
	}
	slog.Info("started", "addr", cfg.Addr)
	signals, stop := signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)
	defer stop()
	<-signals.Done()
	cancel() // shared computations and workers observe the service lifecycle at their next check.
	shutdown, finish := context.WithTimeout(context.Background(), cfg.ShutdownTimeout())
	defer finish()
	if err := server.Shutdown(shutdown); err != nil {
		fatal(err)
	}
	if debug != nil {
		_ = debug.Shutdown(shutdown)
	}
	if err := workers.Wait(shutdown); err != nil {
		fatal(err)
	}
	if err := resolver.Shutdown(shutdown); err != nil {
		fatal(err)
	}
	slog.Info("stopped")
}

本机示例凭据仅用于这个本地参考环境。修改 `.env` 后，Compose 的数据库初始化参数与 app DSN 必须一致；已存在的数据库卷不会因改变初始化环境变量而自动修改账户密码。不要把实际密码提交到 Git。

容器内 app 使用 `mysql:3306`、`redis:6379`；宿主机端口分别为 `13306`、`16379`。app 对外为 `18080`，pprof 为 `16060`，均绑定宿主机回环地址。同步缩放会保存结果文件及 MySQL 索引，依赖 MySQL 可用；Redis 故障允许降级。镜像使用版本标签，尚未拉取核验，也没有固定内容 digest。

### 异步提交、查询、下载

PowerShell 5.1 的原生命令参数传递可能改变 JSON 双引号，因此将 specs 写入文件并用 curl 的字段文件语法传递。

```powershell
$utf8 = New-Object System.Text.UTF8Encoding($false)
$specsFile = Join-Path (Get-Location) '.runtime-data/specs.json'
[System.IO.File]::WriteAllText($specsFile, '[{"width":320,"format":"png"},{"width":160,"format":"jpeg"}]', $utf8)
$accepted = curl.exe -f http://127.0.0.1:18080/jobs -F "file=@.runtime-data/samples/sample-000.png;type=image/png" -F "specs=<$specsFile" | ConvertFrom-Json
$jobId = $accepted.job_id
$job = Invoke-RestMethod "http://127.0.0.1:18080/jobs/$jobId"
$job | ConvertTo-Json -Depth 8
```

稍后重复查询，直到所有规格终止。下载只对 `succeeded` 的规格开放：

```powershell
$job = Invoke-RestMethod "http://127.0.0.1:18080/jobs/$jobId"
foreach ($item in $job.items) {
    if ($item.state -eq 'succeeded') {
        curl.exe -f "http://127.0.0.1:18080$($item.download_url)" -o ".runtime-data/$($item.id).$($item.format)"
    }
}
```

全部 pending 时总状态 pending；任一规格仍处理或部分终止时为 processing；全部终止且任一失败时总状态 failed。成功规格仍可下载，必须查看 items 判断部分成功。

验证同一实例恢复时，始终使用相同数据库和相同数据根目录；容器图片卷与本机 `.runtime-data` 不同，不应在同一数据库上切换不同文件根目录。HTTP、worker 和共享计算都受服务生命周期约束，退出时总等待预算默认 10 秒。

### 真正执行集成测试

集成测试会领取任务、恢复状态和清理自己创建的测试记录，必须使用独立测试数据库。不要指向已有业务任务的数据库。测试还会检查库中不存在 pending/processing 任务，并持有数据库互斥锁。

使用 Compose MySQL 的容器 root 账户创建专用测试库并给 app 授权，保持 app 停止：

```powershell
docker compose stop app
docker compose up -d mysql redis
@'
CREATE DATABASE IF NOT EXISTS image_processor_reference_test;
GRANT ALL ON image_processor_reference_test.* TO 'app'@'%';
'@ | docker compose exec -T mysql sh -c 'MYSQL_PWD=$MYSQL_ROOT_PASSWORD exec mysql -uroot'
$env:REFERENCE_MYSQL_DSN = 'app:local-app-pass@tcp(127.0.0.1:13306)/image_processor_reference_test'
$env:REFERENCE_REDIS_ADDR = '127.0.0.1:16379'
$env:REFERENCE_REQUIRE_INTEGRATION = '1'
go test -v ./internal/integration
Remove-Item Env:REFERENCE_MYSQL_DSN, Env:REFERENCE_REDIS_ADDR, Env:REFERENCE_REQUIRE_INTEGRATION
```

如已更改示例密码，DSN 也要改为本地配置。`REFERENCE_REQUIRE_INTEGRATION=1` 保证缺少真实依赖会失败，避免 CI 悄悄跳过。专用库建库/授权和实际 SQL 尚未在本次运行验证。CI 使用每次新建的服务容器和空数据库，不需要上述手动授权步骤。

### 故障与恢复验收

先记录一次成功任务 ID、输出规格、结果可解码性及 `/stats`。依次进行以下独立实验，保存日志和实际结果；这些操作是用户后续验收步骤，本次未执行。

1. 重复同一文件与规格：`calculations` 增量应为 0；观察 `cache_hits` 或 `persistent_hits`，区别 Redis 与 MySQL 索引复用。
2. `docker compose stop redis` 后再次请求旧规格，再请求新规格：旧结果可由 MySQL 索引复用；新规格需受限计算。`cache_errors` 应增加。`docker compose up -d redis` 后验证补缓存。
3. `docker compose exec redis redis-cli FLUSHDB` 只清除这个参考 Redis 的索引。再次请求旧规格应由 MySQL 回源，计算次数不应增加。该操作不能作为全新计算的基线。
4. 在一项任务为 processing 时执行 `docker compose kill -s SIGKILL app`，然后 `docker compose up -d app`；检查相同任务 ID 恢复到可终止状态，并验证输出。已经达到最多尝试次数的任务会 failed。若任务完成太快，应换成合法大图并在库中确认 processing 后再停止。
5. 用 `docker compose stop app`、`docker compose up -d app` 验证正常停止；用 `docker compose down`、`docker compose up --build -d` 验证容器重建但卷中数据保留。常规停止使用不带 `-v` 的 down，保留卷数据。
6. 测试数据库断连、恢复以及丢失事务回复：观察 worker 是否保留当前领取确认或结束写回的职责。SQL 测试覆盖 token 校验和恢复规则，网络回复丢失需要另行故障注入，不能只凭正常集成测试声称完成。

### 清理与保留策略

默认保留至少 30 天，按创建时间清理已终止任务和没有任务引用的旧结果；这是一项显式维护操作，不自动删除活跃任务，也不按 Redis TTL 删除文件。先停止 app，在持有同一目录锁与数据库锁的前提下预览：

```powershell
docker compose stop app
docker compose run --rm --no-deps --entrypoint /app/cleanup app -config /app/configs/config.yaml -days 30
```

确认预览符合自己的保留要求后，执行同一命令并加 `-apply`，再启动 app。数据库删除提交后才逐个删除已知文件；若文件删除失败，下次维护还能识别孤儿文件。清理 SQL、锁在容器卷上的行为和 apply 效果待真实验证。已有同步结果的创建时间不会因复用自动刷新，按最近使用时间保留需要新增字段和规则。
